# Bootsradar: Downloads

Hier gibt es die Android-App **Bootsradar** zum Herunterladen. Sie sucht gebrauchte Boote auf mehreren Bootsbörsen und Kleinanzeigen-Seiten, mit Fokus auf private Verkäufer.

**Neueste Version:** https://github.com/CaptainBosshaft/bootsradar-releases/releases/latest

## Installieren

1. Den Link oben auf dem Handy öffnen.
2. Unter „Assets“ die Datei `Bootsradar-….apk` antippen und herunterladen.
3. Die heruntergeladene Datei öffnen. Beim ersten Mal fragt Android, ob dein Browser oder Dateimanager Apps installieren darf. Das einmal erlauben.
4. „Installieren“ antippen.

## Updates

Die App sucht selbst nach neuen Versionen und zeigt dann einen Hinweis. Eine neue Version installierst du einfach über die alte. Merkliste und Einstellungen bleiben erhalten.

## Feedback

In der App unter „Mehr“ auf „Feedback senden“ tippen. Dann kannst du deine Rückmeldung zum Beispiel per WhatsApp schicken.

Dies ist eine Testversion. Die Treffer sind noch Beispieldaten, „Zum Artikel“ öffnet aber schon echte Suchen auf den Bootsbörsen.
